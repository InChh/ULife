## 主要更新内容

### 1. 统一接口路径前缀

**修改前：**
- 部分接口使用 `/posts`, `/users`, `/courses`
- 部分接口使用 `/api/v1/` 前缀

**修改后：**
- 所有接口统一使用 `/api/v1/` 前缀
- 遵循 RESTful 规范

**示例：**
```
旧：POST /auth/login
新：POST /api/v1/auth/login

旧：GET /posts
新：GET /api/v1/forum/posts

旧：GET /courses
新：GET /api/v1/courses/public
```

## 接口权限分类

### 无需认证
- `POST /api/v1/auth/login` - 用户登录
- `POST /api/v1/auth/register` - 用户注册
- `GET /api/v1/health` - 健康检查

### 需要认证（普通用户）
- 所有 GET 接口（查看内容）
- POST 接口（发帖、评论、报名等）
- DELETE 接口（删除自己的内容）
- PATCH/PUT 接口（修改自己的内容）

### 需要认证（管理员）
- `POST /api/v1/users/import` - 批量导入用户
- `DELETE /api/v1/users/{id}` - 删除用户
- `GET /api/v1/admin/forum/reports` - 查看举报列表
- `PATCH /api/v1/admin/forum/posts/{id}/status` - 审核帖子

### 需要认证（作者/管理员）
- `DELETE /api/v1/forum/posts/{id}` - 删除帖子
- `DELETE /api/v1/forum/comments/{id}` - 删除评论

## 错误码规范

### HTTP 状态码
- `200` - 请求成功
- `400` - 请求参数错误
- `401` - 未认证或认证失败
- `403` - 无权限
- `404` - 资源不存在
- `409` - 资源冲突（如重复提交、重复注册）
- `413` - 文件过大
- `500` - 服务器内部错误

### 业务状态码（code 字段）
- `200` - 业务成功
- `404` - 资源不存在
- `4091` - 活动报名人数已满
- `4092` - 已报名该活动
- `4093` - 活动报名已截止

## 数据模型规范

### 命名规范
- 使用小驼峰命名：`userId`, `userName`, `createdAt`
- 布尔值使用 `is_` 或 `has_` 前缀：`is_liked`, `is_custom`
- 枚举值使用小写加下划线：`approved`, `pending_review`

### 类型规范
- 整数：`integer`
- 字符串：`string`
- 布尔值：`boolean`
- 日期时间：`string(date-time)` - ISO 8601 格式
- 可空字段：`string¦null`
