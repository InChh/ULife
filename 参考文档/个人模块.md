# 个人模块

Base URLs:

# Authentication

- HTTP Authentication, scheme: bearer
- 大部分接口需要在 Header 中携带 `Authorization: Bearer <token>`
- 登录和注册接口除外

# 通用说明

## 时间格式
- 所有时间字段统一使用 ISO 8601 格式，如：`2024-12-11T10:30:00Z`

## 响应格式
```json
{
  "code": 200,          // 业务状态码，200 表示成功
  "message": "string",  // 状态信息描述
  "data": {}           // 业务数据
}
```

## POST 用户登录

POST /api/v1/auth/login

**权限要求**: 无需认证

## POST 修改密码

POST /api/v1/auth/change-password

已登录用户在知道当前密码的情况下修改密码

**权限要求**: 需要认证  
**注意**: 前端应检查新密码的合法性：与旧密码不一致，密码非空，密码强度符合要求

> Body 请求参数

```json
{
  "old_password": "111111",
  "new_password": "123456"
}
```

|名称|位置|类型|必选|说明|

> 200 Response

```json
{
  "code": 200,
  "message": "密码修改成功",
  "data": null
}
```

```json
{
  "code": 400,
```
