# 论坛模块

Base URLs:

# Authentication

- HTTP Authentication, scheme: bearer
- 所有接口（除特别说明外）均需要在 Header 中携带 `Authorization: Bearer <token>`

# 通用说明

## 时间格式
- 所有时间字段统一使用 ISO 8601 格式，如：`2024-12-11T10:30:00Z`

## 分页参数
- 默认分页参数：`page=1`, `pageSize=20`
- 最大 `pageSize=100`

## 响应格式
```json
{
  "code": 200,          // 业务状态码，200 表示成功
  "message": "string",  // 状态信息描述
  "data": {}           // 业务数据
}
```

## POST 发布新帖子

**权限要求**: 需要认证

  ],

      "type": "image",
