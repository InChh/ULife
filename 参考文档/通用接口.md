# Authentication

- HTTP Authentication, scheme: bearer
- 所有接口均需要在 Header 中携带 `Authorization: Bearer <token>`

# 通用说明

## 时间格式
- 所有时间字段统一使用 ISO 8601 格式，如：`2024-12-11T10:30:00Z`

## 响应格式
```json
{
  "code": 200,          // 业务状态码，200 表示成功
  "message": "string",  // 状态信息描述
  "data": {}           // 业务数据
}
```

# Default

## POST 上传图片/文件

POST /api/v1/storage/upload

通用文件上传接口，支持图片、文档等文件类型

**权限要求**: 需要认证  
**Content-Type**: multipart/form-data  
**支持格式**: 
- 图片：png, jpg, jpeg, gif, webp
- 文档：pdf

**文件限制**:
- 单个文件最大 10MB
- 图片文件会自动生成缩略图

> Body 请求参数

```yaml
file: <binary>
file_type: image

```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|body|body|object| 是 |none|
|» file|body|string(binary)| 是 |要上传的文件|
|» file_type|body|string| 否 |文件类型标识，如：image, document|

#### 枚举值

|属性|值|
|---|---|
|» file_type|image|
|» file_type|document|

> 返回示例

> 200 Response

```json
{
  "code": 200,
  "message": "上传成功",
  "data": {
    "url": "https://oss.example.com/uploads/2024/12/11/abc123.jpg",
    "thumbnail_url": "https://oss.example.com/uploads/2024/12/11/abc123_thumb.jpg",
    "filename": "abc123.jpg",
    "size": 102400
  }
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|上传成功|Inline|
|400|[Bad Request](https://tools.ietf.org/html/rfc7231#section-6.5.1)|请求参数错误|Inline|
|413|[Payload Too Large](https://tools.ietf.org/html/rfc7231#section-6.5.11)|文件过大|Inline|

### 返回数据结构

状态码 **200**

*UploadResponse*

|名称|类型|必选|约束|中文名|说明|
|---|---|---|---|---|---|
|» code|integer|true|none|业务状态码|通常200表示成功|
|» message|string|true|none|状态信息|对code的简要描述|
|» data|object|true|none|上传结果|none|
|»» url|string|true|none|文件URL|文件在对象存储中的永久访问链接 (OSS/S3 URL)|
|»» thumbnail_url|string|false|none|缩略图URL|如果是图片，返回自动生成的缩略图 URL (可选)|
|»» filename|string|true|none|文件名|服务器保存的文件名|
|»» size|integer|true|none|文件大小|文件大小，单位：字节 (Bytes)|

状态码 **400**

*400 Bad Request 响应*

|名称|类型|必选|约束|中文名|说明|
|---|---|---|---|---|---|
|» code|integer|true|none||HTTP 状态码|
|» message|string|true|none||详细的错误提示，如：不支持的文件格式、缺少文件参数|
|» data|object¦null|false|none||错误时 data 字段通常为 null。|

状态码 **413**

*413 Payload Too Large 响应*

|名称|类型|必选|约束|中文名|说明|
|---|---|---|---|---|---|
|» code|integer|true|none||HTTP 状态码|
|» message|string|true|none||错误提示，如：文件大小超过 10MB 限制|
|» data|object¦null|false|none||错误时 data 字段通常为 null。|

## GET 健康检查

GET /api/v1/health

检查服务是否正常运行

**权限要求**: 无需认证

> 返回示例

> 200 Response

```json
{
  "code": 200,
  "message": "Service is running",
  "data": {
    "status": "healthy",
    "timestamp": "2024-12-11T10:30:00Z",
    "version": "1.0.0"
  }
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|服务正常|Inline|

### 返回数据结构

状态码 **200**

*HealthResponse*

|名称|类型|必选|约束|中文名|说明|
|---|---|---|---|---|---|
|» code|integer|true|none||none|
|» message|string|true|none||none|
|» data|object|true|none||none|
|»» status|string|true|none|服务状态|healthy 或 unhealthy|
|»» timestamp|string(date-time)|true|none|时间戳|服务器当前时间|
|»» version|string|true|none|版本号|API 版本号|

#### 枚举值

|属性|值|
|---|---|
|status|healthy|
|status|unhealthy|
