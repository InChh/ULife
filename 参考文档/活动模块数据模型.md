# 活动模块数据模型字段说明

本文档列出了活动模块中所有数据模型的字段定义，用于与接口文档进行对比。

---

## 1. Activity（活动实体）

完整的活动信息，用于活动详情页。

| Swift 属性名 | JSON 字段名 | 类型 | 可选 | 说明 |
|------------|------------|------|------|------|
| id | `id` | String | 否 | 活动唯一标识符 |
| title | `title` | String | 否 | 活动标题 |
| content | `content` | String | 否 | 活动主要内容/介绍 |
| coverUrl | `cover_url` | String | 否 | 活动封面图URL |
| activityType | `activity_type` | ActivityType (Int) | 否 | 活动类型：1-讲座, 2-社团, 3-竞赛 |
| location | `location` | String | 否 | 活动地点 |
| organizer | `organizer` | String | 否 | 主办单位/主办方信息 |
| startTime | `start_time` | Date (ISO8601) | 否 | 活动开始时间 |
| endTime | `end_time` | Date (ISO8601) | 否 | 活动结束时间 |
| quota | `quota` | Int | 否 | 报名人数限额 |
| currentEnrollments | `current_enrollments` | Int | 否 | 当前报名人数 |
| needSignIn | `need_sign_in` | Bool | 否 | 是否需要签到 |
| status | `status` | ActivityStatus (Int) | 否 | 活动状态：1-已发布/进行中, 2-已结束, 3-已撤销 |
| createdAt | `created_at` | Date (ISO8601) | 否 | 创建时间 |
| isEnrolled | `is_enrolled` | Bool? | 是 | 用户是否已报名（详情页字段） |
| isCollected | `is_collected` | Bool? | 是 | 用户是否已收藏（详情页字段） |

## 11. 通用响应模型

| Swift 属性名 | JSON 字段名 | 类型 | 可选 | 说明 |
|------------|------------|------|------|------|

| Swift 属性名 | JSON 字段名 | 类型 | 可选 | 说明 |
|------------|------------|------|------|------|

| data | `data` | String? | 是 | 通常为null |

## 注意事项

1. **日期格式**：所有日期字段使用 ISO8601 格式（如：`2019-08-24T14:15:22Z`）
2. **字段命名**：Swift 使用 camelCase，JSON 使用 snake_case，通过 `CodingKeys` 进行映射
3. **可选字段**：标记为 `可选` 的字段在 JSON 中可能为 `null` 或不存在
4. **枚举类型**：枚举在 JSON 中以整数形式传输，在 Swift 中转换为对应的枚举值
